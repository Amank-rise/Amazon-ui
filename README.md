# Amazon-ui

🛒 Amazon Clone Homepage (HTML & CSS)
A simple front-end clone of Amazon's homepage built using HTML and CSS. It includes a navigation bar, search bar, hero section, product grid, and footer. Designed to practice layout structuring with Flexbox, responsive elements, and real-world UI design.

Features:

* Navigation bar with search and cart

* Hero banner and promo message

* 4 product category boxes

* Multi-column footer with links

Built for learning and showcasing front-end development skills.
